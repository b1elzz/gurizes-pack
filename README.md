# Gurizes RPG Fantasy — pack

Definição do modpack **Gurizes RPG Fantasy** (Forge 1.20.1) no formato [packwiz](https://packwiz.infra.link/), usada pelo instalador dos gurizes.

- Aqui só tem a lista de mods (com os links oficiais do Modrinth/CurseForge e hashes), configs, quests e scripts. **Nenhum jar de mod de terceiro é redistribuído.**
- O mod próprio do pack (`gurizes`) é publicado nas [releases](https://github.com/b1elzz/gurizes-pack/releases).
- Versão atual: **0.1.0 — Ato I**. Os atos seguintes chegam em atualizações.
